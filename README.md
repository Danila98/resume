# Резюме — Данила Кирьянов

Team Lead / Руководитель разработки.

**Онлайн-версия:** [danila98.github.io/resume](https://danila98.github.io/resume/)
**PDF:** [kiryanov-danila-team-lead.pdf](kiryanov-danila-team-lead.pdf)

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Онлайн-версия резюме |
| `print.html` | Версия для печати / пересборки PDF |
| `kiryanov-danila-team-lead.pdf` | Готовый PDF, 2 страницы A4 |
| `css/style.css` | Стили онлайн-версии (светлая и тёмная темы) |
| `css/print.css` | Стили печатной версии |
| `js/main.js` | Переключение темы, анимация появления блоков |

## PDF

Файл в репозитории — **текстовый**, а не картинка: содержимое индексируется
и корректно разбирается системами автоматического отбора резюме (ATS).

Кнопка «Скачать PDF» отдаёт готовый файл. Страница `print.html` нужна,
чтобы пересобрать его после правок текста — через диалог печати браузера
(**Сохранить как PDF**), поля минимальные, фон не печатать.

Вёрстка печатной версии рассчитана ровно на 2 страницы A4. После правок
стоит проверить, что документ не разъехался на третью.

## Локальный запуск

Статика без сборки — достаточно открыть `index.html` в браузере
или поднять любой статический сервер:

```bash
python -m http.server 8000
```
